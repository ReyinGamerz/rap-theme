# Rapelz Hosting — Backup Manager Theme

Dark navy + electric-blue admin UI inspired by the approved mockup.

## Preview locally
This repository is a static, dependency-free prototype. Download/clone it and open `index.html` in a browser, or serve it with any static HTTP server.

## What works in this prototype
- Responsive dark admin layout
- Sidebar navigation and tabs
- Search, source/Node/type/status filters
- Sample backup table with pagination controls
- Backup schedule switches (local demo state only)
- Mock Drive connection and status cards

## Important
All displayed backup rows, IPs, metrics, and activity are **demo data**. This prototype does not connect to a real Pterodactyl installation, Google Drive, or run backup/restore jobs. The integration contract and security requirements live in the `rap-pterodactyl` repository.

## Visual direction
- Navy/near-black surfaces
- Electric blue primary actions
- Compact data-dense tables
- Clear green/red status indicators
- Node-scoped filters rather than one unfiltered backup list
